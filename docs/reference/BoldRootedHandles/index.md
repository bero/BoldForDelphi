# BoldRootedHandles

Defines TBoldRootedHandle

**Description**  
This unit defines TBoldRootedHandle, super class to all handles that are rooted in other handles.

| Classes |
|---|

| **`TBoldRootedHandle`** | TBoldRootedHandle is the superclass for all handles that get their value and type by deriving it from another handle (the RootHandle). |
