# BoldHandles

Defines abstract super classes to the handles.

**Description**  
This unit defines abstract super classes to handles, as well as the concrete class `TBoldSystemTypeInfoHandle`.

| Classes |
|---|

| **`TBoldAbstractSystemHandle`** | Internal. |
|---|---|
| **`TBoldElementHandle`** | Super class to handles that hold a value |
| **`TBoldNonSystemHandle`** | This class introduces the StaticSystemHandle property. It is an abstract class. |
| **`TBoldSystemTypeInfoHandle`** | This handle holds the runtime information needed by a TBoldSystemHandle. |
